Contact

Une offre manque ? Une annonce est erronée ? Une page doit être retirée ? Écrivez-nous. Le relevé est refait chaque jour.

Écrire directement

contact@claimyourjob.fr

Le plus simple, et le plus rapide. Précisez l'employeur et l'intitulé du poste si votre message porte sur une offre en particulier.

Ce que nous traitons le plus souvent

Une entreprise ne figure pas dans le relevé

Indiquez son nom et, si vous l'avez, le lien de sa page carrières. Nous ajoutons la source au relevé.

Une offre est périmée, ou le lien de candidature est mort

Le lien de l'annonce d'origine suffit. Nous corrigeons au cycle suivant.

Une fiche doit être retirée

Un employeur, ou une personne, peut demander le retrait d'une fiche. Nous procédons au retrait.

Une question sur le service, les données ou les CGU

Les données collectées et les conditions d'utilisation répondent à la plupart des questions. Pour le reste, écrivez-nous.

Le formulaire

Le formulaire ci-dessous ouvre votre logiciel de messagerie avec le message prérempli. Il n'envoie rien à un serveur : le message part de votre boîte, ce qui évite qu'il transite par un intermédiaire.

Les champs marqués d'un astérisque sont facultatifs : un message sans nom reste traité.

Délai de réponse

Le relevé étant refait chaque jour, une correction d'annonce est en ligne en général le lendemain. Les demandes de retrait sont traitées en priorité.
